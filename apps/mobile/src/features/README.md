# features

Feature-based modules land here starting Phase 2 (`auth/`), then
`memory-profiles/`, `memory-capture/`, `guided-interview/`,
`memory-conversation/`, etc. as each phase is built — see
`docs/architecture/09-mobile-architecture.md` for the target structure.

Empty in Phase 1 by design: there are no features yet, only infrastructure
(routing, theming, the API health check in `../shared/api-client`).
