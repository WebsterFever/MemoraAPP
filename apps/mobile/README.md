# @memora/mobile

Memora's React Native (Expo) app. See the repo-root `README.md` for full
local setup and `docs/architecture/09-mobile-architecture.md` for the
feature-folder structure and state-management conventions this app follows.

## Scripts

```bash
pnpm --filter @memora/mobile start        # Expo dev server
pnpm --filter @memora/mobile lint
pnpm --filter @memora/mobile typecheck
pnpm --filter @memora/mobile test
```

Copy `.env.example` to `.env` and point `EXPO_PUBLIC_API_URL` at your local
API (default `http://localhost:3000`) before running the app.

> **Note:** this app was scaffolded on Expo SDK 57. `AGENTS.md` in this
> directory is Expo's own reminder (generated by `create-expo-app`) to check
> the versioned docs before assuming older SDK conventions still apply.
